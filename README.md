# RepoPilot AI

A small college project I'm building to understand how the GitHub API works and how Flask can be used to create web applications.

The idea is simple: paste a GitHub repository link, and RepoPilot fetches useful information about the repository and displays it in a clean dashboard.

> **🚧 Project Status:** This project is still under development. New features are being added whenever I get free time.

---

## Current Features

- Analyze public GitHub repositories
- Fetch repository information using GitHub API
- Show stars, forks, language and owner details
- Responsive interface
- Basic error handling

---
